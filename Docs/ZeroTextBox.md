# ZeroTextBox

文本输入框，基于WPF控件扩展，增加圆角等属性。

## 属性

| 属性名             | 参数         | 说明                         |
| ------------------ | ------------ | ---------------------------- |
| CornerRadius       | CornerRadius | 用于设置控件外边框的圆角属性 |
| MaskTextForeground | Brush        | 掩码文本的字体颜色           |
| MaskText           | string?      | 掩码文本，默认Text为空时显示 |
