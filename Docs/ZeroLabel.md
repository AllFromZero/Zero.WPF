# ZeroLabel

标签控件，在WPF基础控件的基础上增加圆角等属性。

## 属性

| 属性名         | 参数         | 说明                                                                                                  |
| -------------- | ------------ | ----------------------------------------------------------------------------------------------------- |
| CornerRadius   | CornerRadius | 用于设置控件外边框的圆角属性                                                                          |
