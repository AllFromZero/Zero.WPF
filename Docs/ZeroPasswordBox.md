# ZeroPasswordBox

密码框，用于数字输入，基于[ZeroTextBox](ZeroTextBox.md)扩展。

## 属性

| 属性名              | 参数   | 说明                 |
| ------------------- | ------ | -------------------- |
| PasswordChar        | char   | 掩码字符，默认为'●'  |
| IsShowPlainPassword | bool   | 是否展示明文密码标致 |
| Password            | string | 密码                 |
| MaskTextForeground | Brush        | 掩码文本的字体颜色           |
| MaskText           | string?      | 掩码文本，默认Text为空时显示 |
